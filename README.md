# Zaměřovač – Android

Samostatná aplikace pro zaměřování nábytku, inspirovaná pracovním postupem ImageMeteru. Projekt vytváří vlastní zdrojový kód a neobsahuje soubory ImageMeteru.

Plánované a rozpracované funkce: složky zákazníků, fotografie s editovatelnými kótami a lupou, kreslení, poznámky, hlasové záznamy, přílohy, videa, Bluetooth laser Bosch a synchronizace zakázek. Vyřazené nástroje: referenční měřítko, perspektivní reference, perspektivní délka, počítadlo a výsledková listina.

**Stav: vývojová verze.** Aplikace zatím nebyla sestavena ani otestována na skutečném Android zařízení. Bluetooth a cloud vyžadují reálné testy. Automatická synchronizace přes Google Disk nemusí fungovat se všemi poskytovateli Android Document Tree.
